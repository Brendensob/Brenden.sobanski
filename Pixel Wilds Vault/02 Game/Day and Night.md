# Day and Night

- A day lasts **216 s**: 99 s of daytime, 45 s of sunset, 72 s of night, then straight back to morning.
- Coming into Pixel Town from the menu always starts in the morning.
- The sky clock at the top turns with the time.
- **Furnaces, eggs, seeds and the daily chests and bounty** run on the game's own clock, not the device clock:
  - It counts with the computer's steady timer, so changing the device clock while playing does nothing.
  - It uses the online server's time when the server can be reached.
  - It never goes back before the last save, so setting the clock back can't rewind anything.
  - Time away from the game still counts, so a furnace finishes while you're gone.
- The **day number only shows in Survival Grasslands**. Brenden: "no one really cares for it".
