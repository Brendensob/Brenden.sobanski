# Git Workflow

- **Repo:** https://github.com/Brendensob/Brenden.sobanski (default branch `main`).
- **Claude's branch:** `claude/festive-cannon-1habiq`.

For each change:
1. Make the change and run [[Testing]].
2. Update the vault: [[Decision Log]], [[Changelog]], the game notes, and a session note.
3. Commit with the attribution trailers the session asks for. **Never put a model name in a commit.**
4. Push the branch, open a PR into `main`, and **merge it**. Brenden wants every change merged.
5. Show Brenden screenshots of the change.

Brenden's own notes come in as commits on `main` from his PC (the desktop shortcut). Merge `main` before starting new work.
