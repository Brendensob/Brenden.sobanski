# How to use this vault

## Open it in Obsidian (one time)
1. Install Obsidian from https://obsidian.md (free).
2. Double-click the **Pixel Wilds** shortcut on your desktop once. It downloads the newest game *and* this vault.
3. In Obsidian, choose **Open folder as vault** and pick:
   `C:\Users\<you>\PixelWilds\Brenden.sobanski\Pixel Wilds Vault`
4. Open [[Home]].

## Keeping it up to date
- Claude writes and updates every note except the ones in `My Notes`.
- The desktop shortcut pulls the newest notes each time you open the game.
- Use **Graph view** (left sidebar) to see how everything links together.

## Talking to Claude through the vault
- Write anything you want Claude to remember in **My Notes**: ideas, wishes, bugs, screenshots.
- The desktop shortcut sends `My Notes` up to GitHub each time you open the game. The first time, Windows may ask you to sign in to GitHub.
- At the start of every session Claude reads [[Home]], [[Rules and Preferences]], [[Open Questions]] and your `My Notes`.

> [!warning] Edit only My Notes
> Notes outside `My Notes` are rewritten by Claude. If you edit one and Claude changes the same note, the shortcut can't update until you undo your edit. Put your thoughts in `My Notes` and Claude will fold them in.

## Templates
In `Templates` you'll find [[Feature Request]], [[Bug Report]] and [[Session Log]]. To use one, copy it into `My Notes` and fill it in.
